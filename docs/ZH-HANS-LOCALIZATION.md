# 简体中文（zh-Hans）本地化约定

本语言包与繁体中文 `zh-Hant` 并存。英文主目录页、所有原版游戏文件及其音视频不参与翻译文件的提交。现有 `zh-Hant` 提供了约 3,105 条完整的 OpenCiv2 / Civilization II 界面、游戏文本、百科和网页内容。本版本以这份资源为基础，使用 OpenCC 台湾词汇到大陆简体中文转换词典，再对高频 UI、安装与存档说明进行人工规则校订；**这仍是机器辅助的待审稿，不冒称已经过完整母语审校**。

## 术语规范（不是逐字转写）

原版专有名字、文明名称及游戏术语应结合《文明》系列语境校对：例如“科技”“回合”“建造”“文明百科”等。避免把媒体播放、用户存档或“桌面”简单逐字翻译成失去游戏语境的词。

## 语言路由

- `zh-CN`、`zh-SG`、`zh-Hans` → `zh-Hans.txt`，浏览器地址可使用 `?lang=zh-CN`。
- `zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant` → `zh-Hant.txt`，不会覆盖原有繁体翻译。
- 英文和其他语言保持不变。两种语言拥有单独的 `@@openciv2.language.name`，在游戏和网页语言选择列表中同时可见。

## 技术兼容性与验收

1. 所有原有 3,105 个键名及 `%s` / `%d` 占位符顺序必须保持一致，`@@codepage` 为 `utf-8`。控制字符、脚本参数、文件名、菜单快捷键不得被自动翻译。
2. 浏览器设置页可以使用系统简体中文字体，但 **WASM 游戏窗口自行绘制字符**；必须在 D 盘上的可信 Git Bash 编译流程中补齐并检查具有 SIL OFL 许可的 Noto 字体字形子集，尤其是转换产生的新简体字。
3. 测试 `?lang=zh-CN` → 网页设置、OpenCiv2 选项、游戏主菜单、存档与导入/导出、顾问面板、文明百科、日期与地图状态；检查缺字、字体错位和 UTF-8 折行。
4. 建议人工抽样复核游戏单位、科技、建筑、外交术语，确保兼顾大陆语言习惯与《文明 II》原有语义。
5. 本地版权资产仍由玩家在 E 盘浏览器文件选择器导入；不会写入 GitHub、静态资源包或 CI 工件。

源繁体文件未修改。转换采用 OpenCC 项目的词汇和字形对应关系（Apache-2.0），最终翻译文本仍受 OpenCiv2 仓库现有许可证约束。详见 `docs/TRANSLATING.md`。

## CIV2-L023 — 原版《文明 II》单位名称核对（优先级 P1）

- **确认调整**：英文单位 `Engineers`（炸药科技解锁、升级殖民者的非战斗地形改造单位）改为 **「工程师」**（简体）／**「工程師」**（繁体）。这不是 `Military Engineer` 工兵；不修改单位 ID、规则、能力、科技依赖或存档。
- 已同步两个中文语言包的 `@@rules.unit.1`、`@@game.ENGINEERS`、`@@describe.UNIT.Engineers`、文明百科、顾问、科技解锁提示和地形命令帮助中**直接指向该单位**的旧称「工兵」，避免单位列表与说明文案出现两个名称。
- 用语依据：2000 年代的《文明Ⅱ》中文攻略明确写 `Engineer（工程师）`，台湾《文明Ⅱ》中文资料的单位表写 `工程師（Engineers）`，中文科技表亦写「炸药可建造工程师」。这些是**可核验的历史中文资料**，不能冒称我们已经取得官方原版完整中文词条或安装介质。研究链接：[多特文明Ⅱ攻略](https://www.duote.com/tech/1/2721.html)、[文明Ⅱ中文百科](https://www.newton.com.tw/wiki/%E6%96%87%E6%98%8E%E2%85%A1/2137842)。
- **已核对且不改**：`Chemistry=化学`、`Explosives=炸药`（繁体：化學、炸藥），与原版科技链以及现有游戏术语一致；不能再误报缺少科技。参考 [B021 #80](https://github.com/ymzuowei/civ2-web/issues/80)。
- **待原版完整文本佐证**：`Settlers` 在当前本地化中作「殖民者」，但旧中文资料同时存在「移民团」「拓荒者」等译法。没有取得该版本原版官方文件之前，不贸然全局替换。顾问口吻、战争用语、建筑名称与城市列表的二次术语核对也放入后续翻译审校清单。
- **保护措施**：仅修改两份 UTF-8 中文源文件和源测试／文档；德语／世界语／拉丁语及其他语言文件的字节、源码 RULES.TXT、原版媒体、SAV/IndexedDB 不变。新字「程／師」已有当前翻译文本的其他词句使用，不需要增加中文字形类别；仍应执行全部语言／字体测试与 Windows WASM 构建。
- **验收范围**：同一存档的「更改生产」列表、单位图鉴、科技解锁提示、地形改造帮助、两种中文语言切换后名称一致；Owner 实机验证之前只可宣称源码翻译完成。
