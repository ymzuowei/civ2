# 简体中文（zh-Hans）本地化约定

本语言包与繁体中文 `zh-Hant` 并存。英文主目录页、所有原版游戏文件及其音视频不参与翻译文件的提交。现有 `zh-Hant` 提供了约 3,105 条完整的 OpenCiv2 / Civilization II 界面、游戏文本、百科和网页内容。本版本以这份资源为基础，使用 OpenCC 台湾词汇到大陆简体中文转换词典，再对高频 UI、安装与存档说明进行人工规则校订；**这仍是机器辅助的待审稿，不冒称已经过完整母语审校**。

## 术语规范（不是逐字转写）

| 繁体 / 台湾习惯 | 大陆简体版本 | 使用场景 |
|---|---|---|
| 軟體 | 软件 | 介绍、系统提示 |
| 檔案 | 文件 | 文件选择器、导入/导出 |

| 記憶體 | 内存 | 性能与资源限制 |

| 網際網路 | 互联网 | 网络帮助 |
| 滑鼠 | 鼠标 | 输入操作 |
| 視窗 | 窗口 | 游戏窗口 |
| 螢幕 / 全螢幕 | 屏幕 / 全屏 | 显示设置 |
| 解析度 | 分辨率 | 清晰度、画面 |
| 光碟映像檔 | 光盘镜像文件 | CUE/BIN 导入 |

原版专有名字、文明名称及游戏术语应结合《文明》系列语境校对：例如“科技”“回合”“建造”“文明百科”等。避免把媒体播放、用户存档或“桌面”简单逐字翻译成失去游戏语境的词。

## 语言路由

- `zh-CN`、`zh-SG`、`zh-Hans` → `zh-Hans.txt`，浏览器地址可使用 `?lang=zh-CN`。
- `zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant` → `zh-Hant.txt`，不会覆盖原有繁体翻译。
- 英文和其他语言保持不变。两种语言拥有单独的 `@@openciv2.language.name`，在游戏和网页语言选择列表中同时可见。

## 技术兼容性与验收

1. 所有原有 3,105 个键名及 `%s` / `%d` 占位符顺序必须保持一致，`@@codepage` 为 `utf-8`。控制字符、脚本参数、文件名、菜单快捷键不得被自动翻译。
2. 浏览器设置页可以使用系统简体中文字体，但 **WASM 游戏窗口自行绘制字符**；必须在 D 盘上的可信 Git Bash 编译流程中补齐并检查具有 SIL OFL 许可的 Noto 字体字形子集，尤其是转换产生的新简体字。
3. 测试 `?lang=zh-CN` → 网页设置、OpenCiv2 选项、游戏主菜单、存档与导入/导出、顾问面板、文明百科、日期与地图状态；检查缺字、字体错位和 UTF-8 折行。
4. 建议人工抽样复核游戏单位、科技、建筑、外交术语，确保兼顾大陆语言习惯与《文明 II》原有语义。
5. 本地版权资产仍由玩家在 E 盘浏览器文件选择器导入；不会写入 GitHub、静态资源包或 CI 工件。

源繁体文件未修改。转换采用 OpenCC 项目的词汇和字形对应关系（Apache-2.0），最终翻译文本仍受 OpenCiv2 仓库现有许可证约束。详见 `docs/TRANSLATING.md`。
